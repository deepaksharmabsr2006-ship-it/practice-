Project 119: Driver Fatigue & Distraction Safety Monitor

End-to-End Automotive Telematics & Edge Computer Vision System. Built using MediaPipe 3D FaceMesh, Biomechanical Feature Aggregation (EAR, MAR, solvePnP Head Pose), Scikit-Learn SVM/Random Forest classifiers, FastAPI backend, WebSockets, and Cloud CI/CD container deployment.

3-Member Individual Contribution Matrix

M1
Deepak Sharma
Team Lead & AI/ML Engineer

Primary Ownership: Computer Vision & Machine Learning Pipeline.

  • MediaPipe 468 3D landmark mesh integration (`facial_landmarks.py`).
  • Mathematical formulation of EAR (Soukupova & Cech) and MAR (`geometry_features.py`).
  • Head Pose Estimation via Perspective-n-Point (`cv2.solvePnP` & Euler decomposition).
  • Rolling 3.0s sliding window feature aggregator (`temporal_buffer.py`).
  • Trained and tuned lightweight SVM & Random Forest classifiers with high-recall focus (`model_trainer.py`).
Viva Defense Focus: Landmark indices, EAR/MAR formulas, PnP camera matrix, SVM RBF kernel parameters, and PERCLOS metric.
M2
Aastha Singh
Backend & Telematics Engineer

Primary Ownership: Backend Architecture, Database & Real-Time APIs.

  • Async FastAPI gateway architecture (`backend/app.py`).
  • SQLAlchemy ORM models: `Driver`, `Trip`, `SafetyIncident`, `TelemetrySnapshot` (`backend/models.py`).
  • Bi-directional WebSocket streaming server for real-time cabin telematics.
  • NHTSA/SAE safety score algorithm calculation (`telematics_service.py`).
  • REST APIs for incident logging, driver dispatch, and audit export (`schemas.py`).
Viva Defense Focus: Async event loops, WebSocket protocol, database indexing, SQLAlchemy session pooling, and Pydantic validation schemas.
M3
Abhishek Shukla
Frontend, Audio & Cloud DevOps

Primary Ownership: Fleet Dashboard UI, Web Audio & Cloud Deployment.

  • Responsive single-page Fleet Operations Console (`frontend/index.html`).
  • Web Audio API multi-tier synthesizer (zero external file dependency alarms).
  • Chart.js live telematics streaming visualizer.
  • Docker multi-stage containerization (`Dockerfile`, `docker-compose.yml`).
  • GitHub Actions CI/CD workflows and 1-click cloud deploy configuration (`render.yaml`, `Procfile`, `vercel.json`).
Viva Defense Focus: Audio synthesis frequencies, Docker image layers, GitHub Actions automated test suites, and Secure Context WebRTC policies.
